### 迭代 0 · 2026-10-13 · 项目启动

**这轮要做什么：** 确定选题、搭好仓库骨架与留痕流程。

**实际做成了什么：** 选题定为「课径 CoursePath」——培养方案可视化规划器，以转专业补修路径为切入点。建立了仓库骨架与 Prompt 导出工具。

**卡住的地方 / 遇到的 Bug：** Windows 上 `python` 命令指向应用商店占位符，无法运行；改用 `py -3.11` 解决。

**我是怎么引导 AI 解决的：** 通过对比 `python --version` 与 `py --version` 的返回码定位到问题，确认机器上同时装有 3.14 与 3.11，选定 3.11 作为项目运行时（生态兼容性更好）。

**下一轮要做什么：** 访谈转专业同学，验证痛点；确定 MVP 范围。
