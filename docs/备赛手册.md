| 评分维度 | 权重 | 核心考察点 |
|---|---|---|
| **过程可复现性与演进链路** | **25%** | Prompt 历史完整、评委可一键复现、代码非拼接 |

## 五、留痕工作流（每次开发照做）

### 开发前
```bash
cd C:\Users\Administrator\Desktop\竞赛\课径    # ⚠️ 必须在这个目录下启动 Claude Code
```
**先开录屏（Win + G）**，再开始。

### 开发中
一次会话只专注一个功能模块。

### 开发后
```bash
# 1. 导出本次的 Prompt 链
py tools/export_prompts.py --label "这次做了什么"

# 2. 只提交本次真正改动的文件（禁止 git add .）
git add <具体文件>
git commit -m "feat: 完成XXX（对应本轮 AI 对话）"

# 3. 补一段人工复盘到 docs/开发日志.md
#    尤其是"遇到什么 Bug、怎么引导 AI 修好的"
```

### 三条铁律
1. **禁止 `git add .` 一把梭**
2. **一个功能模块 = 一次会话 = 一个或几个 commit**
3. **录屏只攒不剪**，存到 `recordings/`（已排除出仓库）

## 六、环境备忘

- Python 用 **`py -3.11`**，不要用 `python`（指向应用商店占位符，会报错）
- 机器上同时有 3.14 和 3.11，**项目统一用 3.11**（生态兼容性更好）
- `.env` 和 `.claude/` 已在 `.gitignore` 中，**提交前务必确认密钥没进仓库**
