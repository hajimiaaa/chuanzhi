> - `class ApiError extends Error`：非 2xx，携带 `status`、`body`，方法 `detailText()` 把后端 `detail`（字符串或 Pydantic 结构化数组）压成一行中文。

> export interface RequestOptions {
>   signal?: AbortSignal
>   timeoutMs?: number
> }
> 
> export async function request&lt;T&gt;(
>   path: string,
>   init: RequestInit = {},
>   { signal, timeoutMs = DEFAULT_TIMEOUT_MS }: RequestOptions = {},
> ): Promise&lt;T&gt;
> 
> export function getJson&lt;T&gt;(path: string, options?: RequestOptions): Promise&lt;T&gt;
> export function postJson&lt;T&gt;(path: string, body: unknown, options?: RequestOptions): Promise&lt;T&gt;

> 2. `fetch(`${API_BASE}${path}`)`；

> 5. 成功返回 `parsed as T`。

> ### 4.2 断言风格
> 
> 典型断言（同文件第 34–39 行、第 54–59 行）：
> 
> ```ts
> it('排到不开课的学期 → blocked，并说明实际开课学期', () =&gt; {
>   const p = program([course('A', 3, [1])])
>   const result = previewDrop(p, [], p.courses[0], 3)
>   expect(result.level).toBe('blocked')
>   expect(result.reason).toContain('第 1 学期')
> })
> 
> it('超过学期学分上限 → warn（不是 blocked）', () =&gt; {
>   const p = program([course('A', 12), course('B', 10)], 20)
>   const items = [{ course_code: 'B', term: 1 }]
>   const result = previewDrop(p, items, p.courses[0], 1)
>   expect(result.level).toBe('warn')
>   expect(result.reason).toContain('22')
> })
> ```
> 
> 风格总结：
> 
> - 结构化返回值用 `toBe` 断言字段，数组/对象整体用 `toEqual`。
> - 用 `toContain` 断言中文提示中的关键信息，不锁完整文案。
> - “无操作”类逻辑用 `toBe(state)` 断言引用相等（例如 `planReducer.test.ts` 第 42、48、122、134 行）。
> - 不 mock 时间、不 mock 网络、不依赖测试顺序。
> - 不写快照，避免中文文案变化导致无意义失败。

> 必剪的ai配音在哪呢

**🤖 AI 的回应**

必剪不同版本菜单名略有差异，但 AI 配音一般在**三个入口之一**，按顺序找：

## 入口一：文本 → 朗读（最常见）

1. 把播放头放到要配音的位置
2. 左侧点「**文本**」→ 新建文本，把这一段文案粘进去
3. 选中这个文本，右侧属性面板里找「**朗读**」/「**AI 配音**」/「**文本转语音**」
4. 选音色、语速（建议 0.9–1.0）→ 生成
5. 生成后音频轨上会多一条配音，把文本删掉或隐藏即可

## 入口二：左侧「音频」面板

有的版本把 AI 配音独立放在「**音频**」→「**AI 配音**」里，选音色后直接生成一条音频，不用先建文本。

## 入口三：顶部搜索框

直接在必剪顶部的搜索框输入「**配音**」或「**朗读**」，能直接跳到对应功能——版本改名了也能找到。

剪映的 AI 配音更成熟，路径是：

```
文本 → 新建文本 → 粘贴文案 → 选中文本 → 朗读 → 选音色（解说小帅 / 青年男声 / 知性女声 …）
```

### 第 38 轮 · 19:58:28

**👤 我的提问**

> 怎么能让他一句一句的出现呢，难道只能一句一句的插入吗

**🤖 AI 的回应**

不用一句一句插。**配音整段生成一条就行，"一句一句出现"是字幕的事，不是音频的事。**

## 正确做法：整段配音 + 自动字幕

1. 把这一段文案**整段**贴进 AI 配音，生成一条音频（七段就是七条，不是几十条）
2. 选中这条音频 → 找「**识别字幕**」/「**语音转字幕**」/「**自动字幕**」
   - 必剪 PC：选中音频轨 → 顶部「文本」里的识别字幕，或右键音频 → 识别字幕
   - 剪映：文本 → 智能字幕 → 识别字幕
3. 它会按停顿自动切句，生成一条**字幕轨**，每句一个文本块，时间已经对好
4. 选中字幕 → 加**入场动画**（打字机 / 渐显）→ 就实现了"一句一句出现"

字幕轨可以整体调样式（字体、描边、位置），不用逐句改。

## 更准的办法：文稿匹配

自动识别偶尔会把"课径"听成别的词。如果你的编辑器有「**文稿匹配**」（剪映有，必剪新版可能叫"文稿匹配/文本朗读对齐"）：

1. 先导入音频
2. 把你的**原文**整段贴进去
3. 它按你写的字切句，再对齐到音频时间

比语音识别准，尤其是"CoursePath""mock"这类词。

## 什么时候才需要真的切音频

只有这两种情况：

- 某一句要换音色/语速
- 某句要和画面精确对拍（比如"我点分数门槛"必须落在点击那一刻）

那时才对音频用「**智能分割**」/「按静音分割」，或单独重新生成那一句。否则一条音频完全够用。

## 一个顺序建议

先配音 → 再识别字幕 → 最后按字幕去微调画面时间点。

不要先剪画面再配音，否则每句都要手动挪，很费时间。
