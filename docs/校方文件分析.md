## 二、制度全貌还原

> 把散在通知全文里的规则整理成一张表——**这件事本身就是产品要做的事**。

### 2.1 资格

| 项 | 规定 |
|---|---|
| 对象 | 2024 级普通全日制本、专科在校生 |
| 次数 | **原则上在校期间最多只能转一次专业** |
| 志愿数 | **每位学生仅可申请 1 个转专业志愿** |
| 硬条件 | 在原专业学习期间，**已修读课程考核全部合格**（即"不能挂科"） |
| 不得转 | ① 艺术、体育专业 → 普通类；② 专升本类 / 五年制高等师范教育类 / 春季高考类 → 普通类；③ 其他经学校审核认为不适合的 |
| 可转情形 | ① 伤病无法在原专业学习；② 原专业停办；③ 休学创业或退役复学；④ 学校认为需调整专业；⑤ **确有学习困难，不转专业无法继续学习** |

### 2.2 考核的触发条件

> 转入学生数超过转入专业**当年招生人数的 30%** 时，需按照转入学院制定的考核方案择优选择。

**关键含义**：绝大多数专业**不设考试**。只有报名人数超过招生数 30% 的热门专业才启动筛选。

### 2.3 时间线（2025 年，针对 2024 级）

| 节点 | 截止日期 |
|---|---|
| 各学院制定并**公示**本学院转专业方案 | 2025-02-14 前 |
| **学生提交申请**（交至转出学院） | **2025-02-21 前** |
| 转出学院内部公示名单（≥3 天） | — |
| 转专业**考核**完成 | 2025-03-03 前 |
| 教务处审核公示（≥3 天） | 2025-03-05 前 |
| 学校审批、发文确定名单 | 2025-03-07 前 |

**全程 21 天。而学生从"方案公示"到"申请截止"只有 7 天。**

### 2.4 办理流程（纸质的、多级签批）

申请表（附件 1）需要 **4 级签字**：

```
本人签字
  → 转出学院意见（院长签字 + 院章）
    → 转入学院意见（院长签字 + 院章）
      → 教务处意见（处长签字）
        → 分管校领导意见（分管校领导签字）
```

纸质版报送**教务处学籍管理科（明理楼 226）**，电子版发邮箱；本表一式两份。

## 三、关键发现

### 发现 A · 官方文件需要"跨章节对读"，且留有解释空间

同一份通知里，两处对"能不能转"给出了**观感完全不同**的表述：

**第一节「转专业审核条件」** 列举的"可以转专业"情形是一个封闭列表，**5 条全部是特殊情形**（伤病、原专业停办、休学创业/退役复学、学校认为需调整、确有学习困难），**没有一条是"单纯对另一个专业有兴趣"**。

**第二节「转专业基本程序」** 则写道：

> 转专业坚持以学生为本，尊重学生自主成才意愿，**转入学院原则上应予以接收**。

**于是产生两种读法**：

| 只读第一节 | 只读第二节 |
|---|---|
| "除非我伤病或确有学习困难，否则转不了" | "想转就能转" |

⚠️ **诚实的限定**：这未必是文件自相矛盾。第 ⑤ 条"确有学习困难的，不转专业无法继续学习的"是宽口径兜底，实操中**可能被解释得很宽**。问题不在于文件错了，而在于：

1. **解释权在学院手里**（第一节另有"其他经学校审核认为不适合转专业的"同样是兜底）
2. **要读完整份文件、还要推测学院会怎么解释**，才能得出结论

这正是学生只能道听途说的**制度性原因**——答案客观存在，但取用成本高到让人放弃。

### 发现 B · 时间窗口只有 7 天

见 2.3。**方案公示（2/14）到申请截止（2/21）之间只有 7 天**，且**每人只能报 1 个志愿**，报错无法重来。

**产品含义**：一个"等学生来搜"的工具救不了人。**倒计时必须主动推**，而且要推到学生还没意识到要查的时候。

### 发现 C · 真实的门槛不在这份文件里 ← 解释了"70 分之谜"

社区帖 C 里，学生焦虑的问题是：

> 转专业难吗，**通识课分数真的要卡到 70 分吗**

而这份校级通知里，**完全没有"70 分"这个数字**。文件只规定了一条：「**已修读课程考核全部合格**」（即不挂科）。

那 70 分从哪来的？通知里埋着答案：

> 各学院转专业工作小组需根据学校统一安排……制定**本学院的转专业工作方案**。方案内容应包括本专业**拟接收学生的计划数**、各环节具体负责人，如申请转入学生超出计划数，拟采取的**考核方案**……
>
> 各学院将确定的转专业方案**在本学院网站公示**。

**推论**：具体门槛（分数、计划数、考核方式）**分散在 21 个学院各自网站上的 21 份方案里**，校级通知只给了框架。

学生要拼出完整答案，需要翻：**1 份校级通知 + 21 份学院方案 + N 份其他文件**——而学院方案散在 21 个网站的角落里。

**这是"信息到不了手"的结构性原因，且完全由官方文件本身推出，不是猜测。**

### 发现 D · 学分认定被甩给了第二份文件

> 在原专业修读课程**学分的认定，按照学校相关学分认定管理方法执行**。

通知**没有**说明怎么认定，只指向另一份文件。

**含义**：「转专业后」的信息真空在制度层面就存在——**连教务处都不在这份文件里回答它。**

### 发现 E · 学校要求学生"充分了解专业"，但没给任何工具 ← **产品的官方授权书**

通知「三、工作要求」第 2 条：

> 各学院应教育学生加强**专业了解和职业规划**，引导学生理性对待转专业。**学生应充分了解所申请专业的相关情况**，根据自己的志趣和能力慎重选择，不可盲目跟从，**以免转专业后造成学习不适应，影响学业**。

这段话官方承认了三件事：

1. 学生**需要**了解所申请专业
2. 学生**需要**做职业规划
3. **了解不足会产生后果**（学习不适应、影响学业）

而校方提供的手段，只有这一句口号。

**这是产品的合法性依据，可直接引用进技术文档。** 我们做的正是学校要学生做、却没有给工具的那件事。

### 发现 F · 专业目录是资格判定的钥匙，不只是清单

《附件 3 专业目录一览表》的 4 列（校区 / 学院 / 专业名称 / 培养层次）中，**培养层次直接对应"不得转专业"条款**：

| 目录里的标注 | 对应通知里的限制 |
|---|---|
| 本科(专科起点)、（专升本） | 专升本类不得转普通类 |
| （春季） | 春季高考类不得转普通类 |
| 学前教育(五年制) | 五年制高等师范教育类不得转普通类 |

而且**附件 2 的填表说明直接指定了它的权威性**：

> "转入、转出专业全称"请务必与《枣庄学院 2024 级专业目录一览表》（见附件 3）内的专业全称一致。

**含义**：专业目录是学校指定的**唯一权威名称源 + 资格判定依据**。把它结构化，等于拿到了产品的主数据地基。（已完成：`data/majors-枣庄学院-2024级.json`）

## 四、与学生调研的交叉验证

把社区帖里学生真正在问的问题，拿去官方文件里找答案：

| 学生的问题（社区原话） | 官方文件里的答案 | 查得到吗 |
|---|---|---|
| 不能挂科？ | 「已修读课程考核全部合格」——**白纸黑字** | ✅ 但埋在条件段里 |
| 通识课真的卡 70 分吗？ | 校级通知里**没有 70 分**这个数字 | ⚠️ 要去 21 个学院网站各自找 |
| 一些专业有面试或者笔试？ | 仅当转入人数 > 招生数 **30%** 时才考核 | ✅ 明确 |
| 空乘（艺术类）能转吗？ | 「艺术、体育专业转到普通类专业的」不得转 | ✅ 但需先判断空乘属艺术类 |
| **跨校区转有限制吗？** | **通知里没说** | ❌ 本文件未覆盖 |
| 学分怎么折抵？ | 「按学校相关学分认定管理方法执行」——指向另一份文件 | ❌ 本文件不覆盖 |

**这张表最有价值的地方，是它同时给出了"产品能做什么"和"产品做不到什么"。**

- 前三行 ✅ —— 答案存在但取用成本高 → **产品价值所在**
- 后两行 ❌ —— **连官方文件都不覆盖** → 产品不能承诺，需在文档中划界

> 注意第 4 行：学生帖里三条互相矛盾的答案（"好像不能转"/"艺术类只能在艺术类里转"/"看官网"），
> **官方文件其实给了确定答案**。学生不是找不到信息，是**没人去读那份文件**。

## 五、文件依赖图：学生要查多少份东西

从这份通知里能追溯出的上游/下游文件：

```
《普通高等学校学生管理规定》（教育部令第 41 号）        ← 国家级，未获取
        └──《枣庄学院普通全日制学生转专业管理暂行办法（试行）》
             （枣院政字〔2017〕165 号）                    ← 校级办法，未获取
              └── 本通知（2024 级）                        ← 已获取 ✅
                   ├── 21 个学院的转专业工作方案            ← 未获取，散在 21 个网站
                   └── 学校学分认定管理办法                ← 未获取，被通知"甩"出去
                        └── 各专业培养方案                 ← 未获取，产品最终要吃的数据
```

**学生要拼出完整答案，至少需要跨 4~5 份文件、21 个网站。**

这就是课径要解决的核心问题：**把这条依赖链收敛成一个视图。**
