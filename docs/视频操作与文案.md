**旁白**

```
转专业之后，最关心的是还差哪些课。
这里可以逐门录入原专业的成绩单，也可以点加载示例成绩单，直接看效果。
这份示例成绩单是三十三门课，模拟一个从软件工程转到计算机科学与技术的学生。
结果是五类，不是一句“还差十三门”。
已认定十七门：课程号对得上、已经通过。
需重修一门：修过但没过。
可能可折抵十门：课名和学分都对得上、但课号不同。大概率是你修过的公共课，能不能顶，要教务处认定。
需补修十三门：成绩单里对不上，按培养方案选课。
待认定五门：原专业独有课程，由学院判断能不能计入。
五类对应五种动作。合并成一句“还差十三门”，就把去选课、去确认、去问，混成了一件。
前四类的学分加起来，严格等于培养方案的一百二十三学分，不存在重复计算。
```

这一轮，我让 AI 做转专业规则模块。需求四类：挂科要求、分数门槛、笔试面试、专业和校区限制。
