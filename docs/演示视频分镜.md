**画面**：应用主界面（培养方案视图），鼠标静止。

**台词**
> 这是课径 CoursePath。

## 第 1 段 · 问题与证据（0:35–1:25）

**画面**：切到浏览器 `docs/校方文件分析.md` 的文件依赖图（或直接切到规则视图的右侧"查不到的类别"）。

**台词**
> 为什么做这个？三份互相独立的证据指向同一个结论：挡住学生的不是能力，是信息到不了手。
>
> 校园社区里，同一个问题——某个专业能不能转出——下面有三个互相矛盾的答案：
> "好像不能转""艺术类只能在艺术类里转""你去看官网"。
> 而官方通知里其实写得清清楚楚。
>
> 更麻烦的是，真正的门槛根本不在校级通知里：通知只说"超过招生数 30% 就要考核"，
> 具体卡多少分、要不要面试，散在 21 个学院各自网站的方案里。
> 学生要拼出答案，得跨四五份文件、二十一个网站。

## 第 2 段 · 功能演示（1:25–4:05）

### 2.1 培养方案：拖错 → 冒红 → 拖回 → AI 解释（1:25–2:45）

**画面**：应用主界面。

**操作**
1. 鼠标悬停「数据结构」课程卡（第 3 学期），拖到第 1 学期 → 松手
2. 右侧冲突面板立刻出现两条红色错误
3. 点击其中一条冲突 → 对应课程卡高亮
4. 把课拖回第 3 学期 → 红色消失
5. 再拖错一次，点右上角「AI 解读」

**台词**
> 打开就是一份可行的规划——它由后端算出来，不是空表。
>
> 我把"数据结构"拖到第一学期。它是第 3 学期的课，而且先修课"程序设计基础"也在第一学期。
> 右边立刻出现两条错误：先修顺序颠倒、开课学期不匹配。点一下冲突，板上的课程卡会联动高亮。
>
> 拖回去，红色消失。
>
> 再拖错一次，点"AI 解读"。注意它是**逐字流式**输出的，上面还显示了解析规划、
> 检测冲突、组织解释、生成文本四个阶段，首字延迟 50 毫秒。
> 这不是前端动画——mock 模式下的流式输出和非流式输出是逐字节相同的，有单测锁住这条等式。

### 2.2 补修核算：转专业之后还差什么（2:45–3:25）

**画面**：点顶部「补修核算」。

**操作**
1. 点「加载示例成绩单」
2. 出现四类清单与统计

**台词**
> 转专业之后，我最关心的是"还差哪些课"。
> 这里录入原专业的成绩单，或者点"加载示例成绩单"。
>
> 结果是四类，不是一句"还差 38 门"：
> 已认定——课程号对得上、已经通过；需重修——修过但没过；
> 需补修——培养方案要求但没修过；待认定——原专业的课，能不能顶要问教务处。
>
> 四类对应四种不同的动作，合并成一类就会误导。
> 这里**不做跨专业折抵**——那需要学校的《学分认定管理办法》，我们没有这份文件，所以不猜。

### 2.3 转专业规则：查不到，也是一种答案（3:25–4:05）

**画面**：点顶部「转专业规则」。

**操作**
1. 展示 17 条条款、8 个分类
2. 点「分数门槛」筛选
3. 鼠标移到右侧高亮的缺口

**台词**
> 这是认知入口：转专业之前查规则。
> 17 条条款按八类分组，每条都带原文的条号和逐字引用。
>
> 我点"分数门槛"——你会看到这一类是 0 条，右边同时高亮对应的缺口：
> 校级通知没有规定任何分数门槛。
>
> 这里有句话我很在意：**"不是我们漏了，是校级通知本身没规定"**。
> 而且这个判断是可以被机器复核的——原文里"门槛""分数线""绩点""70"这几个词，
> 一次都没有出现过。

**（演示段结束，4:05）**

## 第 3 段 · AI 协同过程复现（4:05–6:55，共 2 分 50 秒）

> **这是评分表里"方法创新性与意图控制"的核心证据，也是视频的硬性要求。**
> 本段是**真实历史过程的重演**：下面的 Bug 与对话都真实发生过，重演时用同一条命令复现同样的结果。

### 3.1 让 AI 写一道能证伪自己的校验（4:05–5:35，1 分 30 秒）

**画面**：终端 + `tools/build_rules_json.py`。

**操作**
1. 终端执行：
   ```bash
   py -3.11 tools/build_rules_json.py
   ```
   → `[OK] 17 条条款 / 5 个时间节点 / 5 处缺口`，`[OK] 全部引用与条号已在原文中逐字复核`
2. 在编辑器里，把 `assessment-factors-by-college` 的 `quote` 改一个词：
   把「已修课程学习情况」改成「已修**读**课程学习情况」（**多一个"读"字**）
3. 再执行同一条命令 → `[×] 引用回溯未通过（1 处）……拒绝生成`
4. 画外音讲完，改回去

**台词**
> 这一段是视频里我最想讲的部分。
>
> 规则数据是从官方通知里人工判读出来的。人工判读最大的风险是**以为自己抄对了**。
> 所以我给 AI 的要求不是"帮我整理条款"，而是：**写一道能证伪自己的校验**。
>
> 具体来说：每条条款必须带原文条号和一个逐字引用，生成脚本在落盘之前，
> 把每条引用拿回原文比对，对不上就拒绝生成。
>
> 现在我把引用改错一个字——把"已修课程"改成"已修读课程"，多一个"读"字。
> 再跑一次。
>
> 它拒绝了。报错说：引用回溯未通过，翻译一下就是"你抄错了"。
>
> 这个校验上线后第一次运行就红过一次，抓出的正是这个错误。
> 有意思的是，我另外一份人工整理的分析文档里，同一句话也是这么抄的——
> 两处人工摘录犯了同一个错。所以**拿产物去对照分析文档是发现不了的**，只有回原文才抓得住。

### 3.2 三个"截图看不出来"的 Bug（5:35–6:40，1 分 05 秒）

**画面**：切到浏览器，展示修复后的界面；可叠加一张旧截图或直接口述。

**台词**
> 开发中有三个 Bug 有同一个特征：**程序不报错、页面不异常，功能却缺了一块**。
>
> 第一个，图表的上限线被静默裁掉了——y 轴自动收到 25，而线在 26，落在坐标区外，
> 页面一切正常，只是那条线不见了。
> 第二个更隐蔽：ECharts 没有注册 line 系列，那条线被直接丢弃。这两个叠加在一起，
> 我截了两轮图都以为画好了。
> 第三个是顶栏 tab 的选中态被鼠标悬停样式盖住——两种灰很接近，截图上根本分辨不出来。
>
> 这三个都不是"更仔细地看代码"发现的。是**换了一种验证手段**：
> 用 Playwright 驱动系统已经装好的 Edge，真的去拖、去点，收集控制台错误，
> 并且读元素**计算后的样式**——第三个 Bug 就是读 `getComputedStyle` 才定位的。
>
> 我们的结论是：**能被证伪的东西才值得信。**

### 3.3 过程留痕（6:40–6:55，15 秒）

**画面**：打开 `docs/prompts/` 目录，快速滚动几个文件。

**台词**

> 包含我的提问、AI 的回应、以及我怎么引导它改。提交材料里附了完整的 Prompt 链。

## 第 4 段 · 可复现性（6:55–7:35）

**画面**：终端，仓库根目录。

**操作**
```bash
py -3.11 tools/validate_programs_json.py
py -3.11 tools/validate_rules_json.py
```
（提前清理终端，让输出干净）

**台词**
> 可复现性是这个项目花了最多力气的地方。
>
> 这两条自检命令是**纯标准库**的——不需要装 FastAPI、不需要开虚拟环境，有 Python 就能跑。
> 因为领域模型、约束引擎、数据层只 import 标准库。
>
> 如果领域模型依赖了 Pydantic，这条链就断了：复现门槛会从"有 Python"变成"装完整个 web 栈"。
>
> 完整复现只要三步：起后端、装前端依赖、起前端。全程不需要任何 API Key，
> 默认 mock 模式，所有功能可离线演示。

### 四条原则

1. **结论帧一律 1×，等待与编辑一律加速。** 快进的是过程，不是结果。
2. **静止等待直接剪掉，不要加速**——`Thinking for 8m` 那类画面加速后还是一段静止，
   只会让观众以为卡了。
3. **加速段加角标**（`×8` / `×12`），让评委知道这是加速，不是跳帧或伪造。
4. **成片里的 AI 段控制在 2:40–3:00，其中 1× 的部分不少于 50 秒。**
   全片都加速会让"协同过程"变得不可读，反而不算数。
